## SOC lab

The lab uses VMware to isolate a Windows domain controller, domain workstation, Kali testing host, and Ubuntu-based Splunk server. Windows logs are collected for investigation in Microsoft Sentinel and Splunk.

Current documented work includes:

- Windows Active Directory deployment and domain-joined endpoint
- Microsoft Sentinel onboarding through Azure monitoring
- Splunk Enterprise deployment and Windows log forwarding
- Failed-authentication investigation using Windows Event ID 4625
- KQL and SPL detection queries
- Sysmon-based process and network analysis
- ATT&CK-aligned investigation notes
